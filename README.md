- Busca "Live Server"

- Selecciona "Open with Live Server"

## 🖼️ Personalización

### Cambiar Foto
1. Haz clic en la foto en la invitación
2. Selecciona tu imagen
3. ¡Listo! Se actualiza automáticamente

### Cambiar Información
Edita el archivo `index.html`:

```html
<!-- Busca estas líneas y modifica: -->
<h2>Eileen Luciana</h2>      <!-- Nombre -->
<span class="age-number">10</span>  <!-- Edad -->
<span class="detail-value">14 de Marzo</span>  <!-- Fecha -->
<span class="detail-value">3:00 PM</span>     <!-- Hora -->
<span class="detail-value">Kiosco del Casino de Suboficiales</span>  <!-- Lugar -->
```

### Cambiar Colores
Edita las variables CSS en `styles.css`:

```css
:root {
    --primary: #ff006e;      /* Color principal */
    --secondary: #fb5607;    /* Color secundario */
    --accent: #ffbe0b;       /* Color de acento */
    --purple: #8338ec;       /* Púrpura */
    --cyan: #3a86ff;         /* Azul cian */
}
```
